### Manual

Set Command
```sh
mount /dev/mmcblk0p8 /mnt/cache
mkdir -p /mnt/cache/recovery
cat > /mnt/cache/recovery/command <<'EOF'
--wipe_data
--reason=MasterClearConfirm
--locale=fr_FR
EOF
sync && umount /mnt/cache
```

Set boot mode
```sh
dd if=/dev/zero of=/dev/mmcblk0p5 bs=1088 count=1 conv=notrunc
printf 'boot-recovery\0' | dd of=/dev/mmcblk0p5 bs=1 count=14 conv=notrunc
sync
```

Verify boot mode
```sh
dd if=/dev/mmcblk0p5 bs=1 count=16 2>/dev/null | xxd
```

Reboot to recovery
```
restart
```
